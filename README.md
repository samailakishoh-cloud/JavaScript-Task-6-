CONTACT BOOK 

Project Overview

This project is a simple Contact Book Application developed using JavaScript. It demonstrates the use of arrays, objects, functions, and array methods to manage contact information efficiently.

The application allows users to:

- Add new contacts
- Search for contacts by name
- Display all contacts in alphabetical order

This project was completed as part of Web Development Task 6.


 FEATURES 
 
1. ADD CONTACTS
Users can add a new contact by providing:

- Name
- Phone Number
- Email Address

2. SEARCH CONTACT
   Users can search for a contact using the contact's name.

If the contact exists, the application displays:
- Name
- Phone Number
- Email Address

If the contact does not exist, an appropriate message is displayed.

3. LIST ALL CONTACT
   The application displays all contacts sorted alphabetically by name.
